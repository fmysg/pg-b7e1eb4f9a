Latest quotes

get

https://data.alpaca.markets/v1beta3/crypto/{loc}/latest/quotes

The latest quotes endpoint returns the latest bid and ask prices for the crypto symbols provided.

Skip link to Path Params Path Params

loc

string

enum

required

Skip link to loc

Crypto location from where the latest market data is retrieved.

  • us: Alpaca US
  • us-1: Kraken US
  • eu-1: Kraken EU
