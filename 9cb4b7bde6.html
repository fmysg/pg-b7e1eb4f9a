CDS Declaration and Customs Clearance Request Instructions (UK Trade Tariff: volume 3 for CDS)

Find the guidance, codes and procedures to use when importing or exporting goods when using the Customs Declaration Service (CDS).

From:
: HM Revenue & Customs

Published:
: 1 August 2018

Last updated:
: 1 May 2025 — See all updates

Get emails about this page

This collection brings together guidance, code lists and declaration category data sets to use when making a declaration on the Customs Declaration Service.

You can use the UK Integrated Online Tariff or the Northern Ireland Online Tariff to search for import and export commodity codes as well as the tax, duty and licenses that apply to your goods.

  1. 1 May 2025
    A link to the Simplified Process for Internal Market Movements (SPIMM) and UK Carrier (UKC) Scheme: CDS Declaration and Customs Clearance Request Instructions has been added in order to provide easy access to the guidance should it be required.

  2. 13 June 2023
    This page has been updated to reflect the collection’s new naming conventions. Technical content has not been altered.

  3. 8 July 2022
    A new collection of information and instructions relating to Final Supplementary Declarations (FSD) has been added.

  4. 5 April 2022
    Advice has been added that the collection is being reviewed to update some page names, menus and other terminology. The technical content will remain unchanged and the pages and structure will remain easily identifiable. The updates will be completed with minimum delay.

  5. 11 February 2021
    This page has been updated with the revised CDS volume 3 for import inventory tariff collection. This includes the declaration completion rules, data sets and guidance on declaring goods to a customs procedure. This completes the full Volume 3 collection including the full set of code list appendices to be used for CDS import and export declarations.

  6. 8 February 2021
    This page has been updated with the revised CDS volume 3 inventory export tariff collection. This includes the declaration completion rules and data sets, guidance on entering goods to a customs procedure to be used for CDS inventory export declarations.

  7. 21 December 2020
    This page has been updated with supplements which detail the customs requirements for the movement of goods between Great Britain and Northern Ireland, and, goods to and from Great Britain.

  8. 4 December 2020
    This page has been updated with the revised CDS volume 3 for exports tariff collection. This includes the declaration completion rules, data sets and guidance on declaring goods to a customs procedure. It accompanies the import tariff collection and the full set of code list appendices to be used for CDS import and export declarations. The inventory CDS Volume 3 Tariff collections will be made available on GOV.UK at a later date.

  9. 16 October 2020
    This page has been updated with the revised CDS volume 3 for imports tariff collection. This includes the declaration completion rules and data sets, guidance on entering goods to a customs procedure and the full set of code list appendices to be used for CDS import declarations. The export and inventory CDS Volume 3 Tariff collections will be made available on GOV.UK at a later date.
